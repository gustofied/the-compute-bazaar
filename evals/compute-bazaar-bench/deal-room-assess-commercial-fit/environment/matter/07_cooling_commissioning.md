# Helsinki Hall A/D Liquid-Cooling Commissioning Record

Issued: 2026-07-23

## Certified capacity

The Hall A direct-to-chip loop has passed load testing for 48 Northlink nodes,
equal to 384 B200 GPUs. It is certified for production use from 2026-10-01.

## Capacity not yet certified

The Hall D loop intended for the remaining 16 nodes has not completed pressure,
failover, or full-load testing. Standard completion is scheduled for
2026-11-15.

The full 64-node cluster is not currently supported by a completed
commissioning record for the 2026-10-15 buyer date.
