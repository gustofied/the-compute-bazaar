# Evaluations

This directory contains the maintained evaluation source for
`compute-bazaar-bench`.

- [`reliability-is-blind`](reliability-is-blind/README.md) is an implemented
  interactive brokerage evaluation.
- [`transactions`](transactions/README.md) is the professional-work domain. Its
  first three task adaptations are currently planned.

Generated Harbor jobs and private reports belong in `../jobs/`, not beside the
task source.
