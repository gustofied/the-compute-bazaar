# compare-capacity-agreement-against-term-sheet

**Status:** planned

**Stage:** contracting

**Harvey analogue:**
[Compare PPA against term sheet](https://hub.harborframework.com/tasks/punitarani/energy-natural-resources-compare-power-purchase-agreement-against-term-sheet/latest).

The source task combines a binding term sheet, executed agreement,
negotiation-summary email, financing checklist, and a deviation report with 43
rubric criteria.

The compute adaptation will use an agreed compute-capacity term sheet, a draft
reserved-capacity agreement or order form, a negotiation-summary email, and a
buyer technical, finance, and risk checklist. The deliverable will be a
`capacity-agreement-deviation-report.docx` covering price escalation, power
pass-through, delivery, deposits, configuration, SLA terms, credits,
termination, assignment, and resale. Each deviation must be classified,
quantified, and tied to a recommended action.
