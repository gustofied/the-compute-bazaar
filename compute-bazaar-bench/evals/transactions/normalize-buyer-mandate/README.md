# normalize-buyer-mandate

**Status:** planned

**Stage:** intake

**Harvey analogue:**
[Extract disorganized client-intake facts](https://hub.harborframework.com/tasks/punitarani/trusts-estates-private-client-extract-client-intake-facts-scenario-01/latest).

The source task combines a disorganized intake questionnaire, a follow-up
email, a controlling supporting document, and a structured key-facts memo with
56 rubric criteria.

The compute adaptation will use a buyer RFQ or intake form, a follow-up message
thread, and workload and technical requirements. The deliverable will be a
`buyer-mandate-brief.docx` that distinguishes requirements from preferences,
reconciles conflicting details, verifies calculations, preserves uncertainty,
and identifies questions that must be answered before approaching suppliers.
