# Private calibration archive

This directory preserves grader and run-development material from private calibration. It is not part of the default public benchmark view.

- `verifier-v1/` preserves the first grader.
- `../../adjudication/` preserves the corrected replay and its evidence audit.
- `../../protocols/transactions-comparison-v1.*` preserves the first comparison protocol.
- `protocols/` preserves the retired Mistral Medium baseline locks.
- `results/` preserves the earlier comparison and Mistral Medium reports.
- `releases/` preserves the retired Mistral Small release work.
